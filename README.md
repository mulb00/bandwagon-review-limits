年付 $49.99 的 KVM 基础款看着不贵，但它走的是普通国际线路，搬瓦工真正值得买的是 CN2 GIA-E 系列——年付 $169.99 起；香港 CN2 GIA 月付 $89.99 起，一年接近 900 美元。早年 $19/年 的 OpenVZ 时代早就结束了，2019 年它取消了所有年付 $20 以内的套餐，彻底转向中高端市场。预算有限的个人用户，市面上确实有更便宜的选择。

缺货是第二大槽点。性价比最高的限量版套餐常年缺货：比如 2核2GB 的 MEGABOX-PRO 卖 $49/年，同配置的常规套餐要 $299.99/年，但补货后几小时内就会售罄，没有蹲补货通知的耐心基本抢不到。

接下来这几个问题，很多推荐文章不会展开：

- **没有 DDoS 防护。** 所有套餐都不内置抗 D，被大流量攻击会直接空路由（Nullroute），一般 30 分钟后恢复，长期被攻击就很难受。建站用户需要自己套 CDN。
- **换 IP 收费。** IP 被封后更换一次收 $8。
- **Netflix 解锁看运气。** 有些 IP 能解锁有些不能，官方不做任何保证，主追流媒体的话选专门商家更稳。
- **性能中等偏下。** 超售是常态，不同套餐的 CPU 性能限制也不一样。2025 年起的新 Box 系列限量款换上了 AMD EPYC 处理器和 NVMe RAID-10 硬盘，性能提升明显，对性能有要求的话优先等新款。
- **客服只有工单。** 没有实时在线聊天，一般 24 小时内回复，习惯即时沟通的人会觉得别扭。

### 机房切换有边界

多机房切换是搬瓦工的招牌，但规则有边界。只有 CN2 GIA-E 这类套餐能在 CN2 GIA、软银、AS9929 这些优化线路的机房间自由切换；普通 KVM 套餐只能在自己那组机房里换；香港、日本这类亚洲 CN2 GIA 机房，无法通过低价套餐切换过去。
